# Route Tranquille

Progressive Web App bilingue (français / serbe) destinée aux camping-caristes seniors.

Site : https://cyrilandro.github.io/route-tranquille/

- Fonctionnement hors ligne
- Services utiles avec géolocalisation
- Numéros d'urgence France et Serbie
- Informations personnelles conservées uniquement sur l'appareil
- Sans backend ni dépendance externe
